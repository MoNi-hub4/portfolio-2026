# Tool logo sources

All 12 logo image links were publicly accessible when this update was prepared. Copies are bundled in `public/logos/` and served by the portfolio itself. No extra npm package or API key is needed.

Eleven assets come from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0). The Tesseract.js asset is the dark-theme logo used in the [official Tesseract.js repository](https://github.com/naptha/tesseract.js).

PySpark is the Python API for Apache Spark, so its card uses the Apache Spark symbol, consistent with [PySpark's documentation](https://spark.apache.org/docs/latest/api/python/index.html).

The Express SVG keeps the original vector paths; only empty space in its viewBox is trimmed. CSS displays this monochrome wordmark in white for readability on the dark card. The remaining assets retain their original colors. JavaScript and TypeScript use their recognizable letter-based brand logos rather than typed placeholder initials.
