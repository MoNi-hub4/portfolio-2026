# Sample project screenshots

These nine images are temporary public-repository UI samples selected to demonstrate the portfolio layout. They are not screenshots of Monishan’s own applications. The site labels them as samples and credits each source.

The first image for each project appears on its card. **View Project** opens all three images, plus a written, clickable website URL. The included demo URLs belong to the sample projects; no personal project URL has been invented.

## Replace the samples

1. Replace the three PNG files for each project in `public/images/projects/`, or change its three `images` paths in `src/data.ts`.
2. Set `liveUrl` to your own deployed project URL, including `https://`.
3. Set `sourceUrl` if you want a link to your own public code repository.
4. Remove that project’s `sample` object. This removes the sample labels, attribution, and fallback demo link.
